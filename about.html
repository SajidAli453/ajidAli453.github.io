About

This site provides free maths calculators for students, teachers and everyday users. The tools cover percentages, discounts, age, scientific calculations, averages, area and time duration — the calculations people look up most often.

Every tool is built to be used without signing up or downloading anything. Calculations happen in your browser, and each tool page explains the method, gives a worked example, and lists common mistakes, so the site is useful for learning as well as for quick answers.

The site is run as an education project. It is not a substitute for professional advice, and important decisions should always be double-checked — see the Disclaimer page.
