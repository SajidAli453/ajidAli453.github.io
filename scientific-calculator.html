What this tool does

This scientific calculator goes beyond addition, subtraction, multiplication and division. It handles trigonometry and inverse trigonometry, base-10 and natural logarithms, powers and roots, factorials, percentages, and the constants pi and e. Memory buttons let you store a result and reuse it, and the Ans value is the last calculated result.

How to use it, step by step

  1. Check the angle mode first: Deg for most school problems, Rad for many university and programming problems.
  2. Enter your expression with the buttons or keyboard, using brackets to control the order of operations.
  3. Press = to calculate. Press Clear to start again, or Backspace to fix one character.
  4. Use M+ to add the current answer to memory, MR to insert the memory value, and MC to clear memory.

Worked examples

Powers: 2^5 = 32, because 2 × 2 × 2 × 2 × 2 = 32. Roots: √(144) = 12, because 12 × 12 = 144. Trigonometry: sin(30) in Deg mode = 0.5, a classic result for a 30-degree angle in a right-angled triangle. Logarithms: log(100) = 2, because 10² = 100.

Common mistakes

  • Wrong angle mode: sin(30) gives 0.5 in degrees but about −0.988 in radians. Always check Deg/Rad before trusting a trig answer.
  • Missing brackets: 10 + 5 × 2 = 20, while (10 + 5) × 2 = 30. Brackets change the order, so use them deliberately.
  • Factorials of large or non-whole numbers: factorials here are for whole numbers; very large factorials grow extremely fast and may overflow.
  • Logarithms of zero or negative numbers: these are not defined for real results, so the calculator will show an error. Check the input.

Frequently asked questions

What is the difference between log and ln?

Log here means base-10 logarithm, while ln means natural logarithm, base e (about 2.718). Log(100) = 2, while ln(e) = 1.

How do I enter a power?

Use the ^ button: type 2, then ^, then 5, then = to get 32.

What does Ans mean?

Ans is your last answer. You can use it as a starting point for the next calculation without retyping it.

Can I use it on a phone?

Yes. The buttons are sized for touch, and the layout adjusts on small screens. Keyboard input works on a computer.
